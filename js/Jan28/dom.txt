1. WHAT IS DOM?
================================================================================

DOM = Document Object Model

Think of DOM as a TREE STRUCTURE:
- Your HTML page is like a family tree
- Every element (tag) is a "node" in the tree
- JavaScript can read, change, add, or remove any node

EXAMPLE HTML:
-------------
<html>
  <body>
    <h1>Hello</h1>
    <p>World</p>
  </body>
</html>

DOM TREE:
---------
        html
          |
        body
        /   \
      h1     p

WHY IS DOM IMPORTANT?
---------------------
- Makes your website INTERACTIVE
- Without DOM, websites would be static (boring!)
- DOM lets you respond to user actions (clicks, typing, scrolling)
- You can change content without reloading the page

2. HOW TO ACCESS/SELECT ELEMENTS
================================================================================

There are 5 MAIN WAYS to select elements:

METHOD 1: getElementById()
--------------------------
- Selects ONE element by its id
- Returns: Single element OR null (if not found)
- Fastest method

HTML:
<div id="myDiv">Hello</div>

JAVASCRIPT:
let element = document.getElementById("myDiv");
console.log(element); // <div id="myDiv">Hello</div>

REMEMBER: 
- id should be UNIQUE (only one per page)
- Don't include # symbol
- Case-sensitive


METHOD 2: getElementsByClassName()
----------------------------------
- Selects ALL elements with that class name
- Returns: HTML Collection (array-like)
- Live collection (updates automatically)

HTML:
<p class="text">First</p>
<p class="text">Second</p>
<p class="text">Third</p>

JAVASCRIPT:
let elements = document.getElementsByClassName("text");
console.log(elements.length); // 3
console.log(elements[0]); // First <p>
console.log(elements[1]); // Second <p>

// Loop through all elements
for(let i = 0; i < elements.length; i++) {
    console.log(elements[i].textContent);
}

REMEMBER:
- Returns collection even if only one element found
- Don't include . symbol
- Case-sensitive


METHOD 3: getElementsByTagName()
--------------------------------
- Selects ALL elements with that tag name
- Returns: HTML Collection (array-like)
- Live collection

HTML:
<p>Paragraph 1</p>
<p>Paragraph 2</p>
<div>A div</div>

JAVASCRIPT:
let paragraphs = document.getElementsByTagName("p");
console.log(paragraphs.length); // 2

let allDivs = document.getElementsByTagName("div");
console.log(allDivs.length); // 1

REMEMBER:
- Tag name should be lowercase
- Returns all matching tags


METHOD 4: querySelector()
--------------------------
- Selects FIRST element that matches CSS selector
- Returns: Single element OR null
- Most flexible but slightly slower

HTML:
<div class="container">
  <p class="text">First</p>
  <p class="text">Second</p>
</div>

JAVASCRIPT:
// Select by class (use .)
let firstText = document.querySelector(".text");
console.log(firstText); // First <p>

// Select by id (use #)
let container = document.querySelector("#myId");

// Select by tag
let paragraph = document.querySelector("p");

// Complex selectors
let nestedP = document.querySelector(".container p");
let firstChild = document.querySelector("div > p:first-child");

REMEMBER:
- Use CSS selectors (. for class, # for id)
- Returns ONLY the first match


METHOD 5: querySelectorAll()
-----------------------------
- Selects ALL elements that match CSS selector
- Returns: NodeList (array-like)
- Static collection (doesn't update automatically)

HTML:
<p class="text">First</p>
<p class="text">Second</p>
<p class="text">Third</p>

JAVASCRIPT:
let allText = document.querySelectorAll(".text");
console.log(allText.length); // 3

// Loop with forEach (NodeList has forEach)
allText.forEach(function(element) {
    console.log(element.textContent);
});

// Or traditional loop
for(let i = 0; i < allText.length; i++) {
    console.log(allText[i].textContent);
}

REMEMBER:
- Returns NodeList, not HTML Collection
- Can use forEach directly on NodeList


WHICH METHOD TO USE?
--------------------
- Need ONE element with unique id? → getElementById()
- Need multiple elements by class? → getElementsByClassName() or querySelectorAll()
- Need ALL of a tag type? → getElementsByTagName()
- Need complex CSS selection? → querySelector() or querySelectorAll()
- Best practice: Use querySelector/querySelectorAll for flexibility

3. READING AND CHANGING CONTENT
================================================================================

There are 3 MAIN PROPERTIES to work with content:

PROPERTY 1: textContent
-----------------------
- Gets or sets the TEXT inside an element
- Ignores HTML tags
- Shows hidden elements too

HTML:
<p id="demo">Hello <strong>World</strong></p>

JAVASCRIPT:
let p = document.getElementById("demo");

// READ text
console.log(p.textContent); // "Hello World"

// CHANGE text
p.textContent = "New Text";
// Result: <p id="demo">New Text</p>


PROPERTY 2: innerHTML
---------------------
- Gets or sets HTML inside an element
- Interprets HTML tags
- Can insert new HTML

HTML:
<div id="container">Hello</div>

JAVASCRIPT:
let div = document.getElementById("container");

// READ HTML
console.log(div.innerHTML); // "Hello"

// CHANGE with HTML
div.innerHTML = "<strong>Bold Text</strong>";
// Result: <div id="container"><strong>Bold Text</strong></div>

// ADD to existing content
div.innerHTML += "<p>More content</p>";

WARNING: Be careful with user input! innerHTML can cause security issues (XSS attacks)


PROPERTY 3: innerText
----------------------
- Similar to textContent but respects CSS styling
- Doesn't show hidden elements
- Takes CSS into account

HTML:
<p id="text" style="display:none">Hidden</p>

JAVASCRIPT:
let p = document.getElementById("text");

console.log(p.textContent); // "Hidden" (shows hidden text)
console.log(p.innerText); // "" (respects display:none)

WHICH ONE TO USE?
-----------------
- Plain text? → textContent (faster)
- Need HTML tags? → innerHTML
- Respect CSS visibility? → innerText
- Most common: textContent and innerHTML


PRACTICAL EXAMPLES:
-------------------

// Example 1: Change heading text
let heading = document.querySelector("h1");
heading.textContent = "Welcome to My Website";

// Example 2: Update paragraph with HTML
let para = document.getElementById("myPara");
para.innerHTML = "This is <em>important</em> information!";

// Example 3: Display user name
let userName = "John";
let greeting = document.querySelector(".greeting");
greeting.textContent = "Hello, " + userName + "!";
// OR using template literals
greeting.textContent = `Hello, ${userName}!`;

// Example 4: Add to existing content
let list = document.getElementById("myList");
list.innerHTML += "<li>New Item</li>";

4. WORKING WITH ATTRIBUTES
================================================================================

Attributes are extra information in HTML tags (id, class, src, href, etc.)

METHOD 1: getAttribute()
------------------------
- Gets the value of an attribute
- Returns: String OR null

HTML:
<img id="myImg" src="photo.jpg" alt="A photo">
<a id="myLink" href="https://google.com">Google</a>

JAVASCRIPT:
let img = document.getElementById("myImg");
console.log(img.getAttribute("src")); // "photo.jpg"
console.log(img.getAttribute("alt")); // "A photo"

let link = document.getElementById("myLink");
console.log(link.getAttribute("href")); // "https://google.com"


METHOD 2: setAttribute()
-------------------------
- Sets or changes an attribute value
- If attribute doesn't exist, it creates it

JAVASCRIPT:
let img = document.getElementById("myImg");

// Change existing attribute
img.setAttribute("src", "new-photo.jpg");

// Add new attribute
img.setAttribute("title", "Beautiful photo");

// Result: <img id="myImg" src="new-photo.jpg" alt="A photo" title="Beautiful photo">


METHOD 3: removeAttribute()
----------------------------
- Removes an attribute completely

JAVASCRIPT:
let img = document.getElementById("myImg");
img.removeAttribute("alt");
// Result: <img id="myImg" src="photo.jpg">


METHOD 4: hasAttribute()
-------------------------
- Checks if element has an attribute
- Returns: true or false

JAVASCRIPT:
let img = document.getElementById("myImg");

if(img.hasAttribute("alt")) {
    console.log("Has alt text");
} else {
    console.log("No alt text");
}


DIRECT PROPERTY ACCESS:
-----------------------
You can also access common attributes directly:

JAVASCRIPT:
let img = document.getElementById("myImg");

// Read
console.log(img.src); // Direct property
console.log(img.alt);
console.log(img.id);

// Write
img.src = "new-image.jpg";
img.alt = "New description";

let link = document.getElementById("myLink");
link.href = "https://youtube.com";


PRACTICAL EXAMPLES:
-------------------

// Example 1: Change image source
let img = document.querySelector("img");
img.src = "new-photo.jpg";

// Example 2: Make link open in new tab
let link = document.querySelector("a");
link.setAttribute("target", "_blank");

// Example 3: Disable a button
let button = document.getElementById("submitBtn");
button.setAttribute("disabled", "true");
// OR
button.disabled = true;

// Example 4: Change input placeholder
let input = document.querySelector("input");
input.setAttribute("placeholder", "Enter your name");
// OR
input.placeholder = "Enter your name";

// Example 5: Check if link has href
let link = document.querySelector("a");
if(link.hasAttribute("href")) {
    console.log("Link goes to: " + link.href);
}

5. MANIPULATING CSS STYLES AND CLASSES
================================================================================

There are 2 MAIN WAYS to change styling:

WAY 1: INLINE STYLES (style property)
--------------------------------------
- Changes CSS directly on the element
- Creates inline styles
- Use camelCase for CSS properties (background-color → backgroundColor)

HTML:
<p id="myText">Hello</p>

JAVASCRIPT:
let text = document.getElementById("myText");

// Change single style
text.style.color = "red";
text.style.fontSize = "20px";
text.style.backgroundColor = "yellow";

// Result: <p id="myText" style="color: red; font-size: 20px; background-color: yellow;">Hello</p>

IMPORTANT CSS PROPERTY NAMES:
------------------------------
CSS:                JavaScript:
background-color → backgroundColor
font-size       → fontSize
margin-top      → marginTop
border-radius   → borderRadius
text-align      → textAlign

EXAMPLE:
let div = document.querySelector("div");
div.style.backgroundColor = "blue";
div.style.padding = "20px";
div.style.borderRadius = "10px";
div.style.color = "white";


WAY 2: CSS CLASSES (classList)
-------------------------------
- Better practice than inline styles
- Cleaner and more maintainable
- Define styles in CSS, apply with JavaScript

HTML:
<style>
  .highlight {
    background-color: yellow;
    font-weight: bold;
  }
  .large-text {
    font-size: 24px;
  }
</style>

<p id="myText">Hello World</p>

JAVASCRIPT:
let text = document.getElementById("myText");


classList.add() - Add a class
------------------------------
text.classList.add("highlight");
// Result: <p id="myText" class="highlight">Hello World</p>

// Add multiple classes
text.classList.add("highlight", "large-text");
// Result: <p id="myText" class="highlight large-text">Hello World</p>


classList.remove() - Remove a class
------------------------------------
text.classList.remove("highlight");
// Removes only highlight class


classList.toggle() - Add if absent, remove if present
------------------------------------------------------
text.classList.toggle("highlight");
// If class exists → removes it
// If class doesn't exist → adds it

// Perfect for:
// - Show/Hide
// - Dark mode / Light mode
// - Active/Inactive states

EXAMPLE: Dark Mode Toggle
let body = document.body;
let toggleBtn = document.getElementById("darkModeBtn");

toggleBtn.addEventListener("click", function() {
    body.classList.toggle("dark-mode");
});


classList.contains() - Check if class exists
---------------------------------------------
if(text.classList.contains("highlight")) {
    console.log("Element is highlighted!");
} else {
    console.log("Element is not highlighted");
}


classList.replace() - Replace one class with another
-----------------------------------------------------
text.classList.replace("highlight", "warning");
// Removes 'highlight' and adds 'warning'


PRACTICAL EXAMPLES:
-------------------

// Example 1: Highlight selected item
let items = document.querySelectorAll(".item");

items.forEach(function(item) {
    item.addEventListener("click", function() {
        // Remove highlight from all
        items.forEach(i => i.classList.remove("selected"));
        // Add to clicked item
        item.classList.add("selected");
    });
});


// Example 2: Show/Hide element
let modal = document.getElementById("modal");
let showBtn = document.getElementById("showModal");
let hideBtn = document.getElementById("hideModal");

showBtn.addEventListener("click", function() {
    modal.classList.remove("hidden");
});

hideBtn.addEventListener("click", function() {
    modal.classList.add("hidden");
});


// Example 3: Change button state
let button = document.getElementById("myBtn");

// Make button look disabled
button.classList.add("disabled");
button.disabled = true;

// Make button look enabled
button.classList.remove("disabled");
button.disabled = false;


WHICH METHOD TO USE?
--------------------
✅ USE classList (RECOMMENDED):
   - Multiple styles to change
   - Reusable styles
   - Cleaner code
   - Better performance

⚠️ USE style property:
   - Quick one-off changes
   - Dynamic values (calculated colors, positions)
   - Overriding important styles

6. CREATING AND ADDING NEW ELEMENTS
================================================================================

STEP-BY-STEP PROCESS:
1. Create the element
2. Add content to it
3. (Optional) Add attributes/styles
4. Insert it into the DOM


STEP 1: Create Element - createElement()
-----------------------------------------
let newElement = document.createElement("tagName");

EXAMPLES:
let newDiv = document.createElement("div");
let newPara = document.createElement("p");
let newButton = document.createElement("button");
let newImg = document.createElement("img");
let newLink = document.createElement("a");


STEP 2: Add Content
--------------------
newElement.textContent = "Text here";
// OR
newElement.innerHTML = "<strong>HTML</strong> here";

EXAMPLE:
let newPara = document.createElement("p");
newPara.textContent = "This is a new paragraph";


STEP 3: Add Attributes/Styles (Optional)
-----------------------------------------
newElement.setAttribute("class", "myClass");
newElement.id = "myId";
newElement.style.color = "blue";

EXAMPLE:
let newButton = document.createElement("button");
newButton.textContent = "Click Me";
newButton.id = "myBtn";
newButton.classList.add("btn", "btn-primary");


STEP 4: Insert Into DOM
------------------------
There are MULTIPLE methods to insert:


METHOD 1: appendChild()
-----------------------
- Adds element as LAST CHILD
- Most common method

HTML BEFORE:
<div id="container">
  <p>First</p>
</div>

JAVASCRIPT:
let container = document.getElementById("container");
let newP = document.createElement("p");
newP.textContent = "Second";
container.appendChild(newP);

HTML AFTER:
<div id="container">
  <p>First</p>
  <p>Second</p> ← Added here
</div>


METHOD 2: insertBefore()
-------------------------
- Inserts element BEFORE a specific child
- Syntax: parent.insertBefore(newElement, referenceElement)

HTML BEFORE:
<div id="container">
  <p id="second">Second</p>
</div>

JAVASCRIPT:
let container = document.getElementById("container");
let second = document.getElementById("second");
let newP = document.createElement("p");
newP.textContent = "First";
container.insertBefore(newP, second);

HTML AFTER:
<div id="container">
  <p>First</p> ← Added here
  <p id="second">Second</p>
</div>


METHOD 3: append()
------------------
- Modern method (newer)
- Can append multiple items at once
- Can append text directly

JAVASCRIPT:
let container = document.getElementById("container");
let p1 = document.createElement("p");
p1.textContent = "Para 1";
let p2 = document.createElement("p");
p2.textContent = "Para 2";

// Append multiple
container.append(p1, p2, "Some text");


METHOD 4: prepend()
-------------------
- Adds as FIRST child
- Opposite of append()

HTML BEFORE:
<div id="container">
  <p>Last</p>
</div>

JAVASCRIPT:
let container = document.getElementById("container");
let newP = document.createElement("p");
newP.textContent = "First";
container.prepend(newP);

HTML AFTER:
<div id="container">
  <p>First</p> ← Added here
  <p>Last</p>
</div>


METHOD 5: insertAdjacentHTML()
-------------------------------
- Insert HTML at specific position
- Very flexible

POSITIONS:
- "beforebegin" - Before the element
- "afterbegin" - Inside, as first child
- "beforeend" - Inside, as last child
- "afterend" - After the element

HTML BEFORE:
<div id="container">
  <p>Middle</p>
</div>

JAVASCRIPT:
let container = document.getElementById("container");
container.insertAdjacentHTML("afterbegin", "<p>First</p>");
container.insertAdjacentHTML("beforeend", "<p>Last</p>");

HTML AFTER:
<div id="container">
  <p>First</p> ← afterbegin
  <p>Middle</p>
  <p>Last</p> ← beforeend
</div>


PRACTICAL EXAMPLES:
-------------------

// Example 1: Add item to shopping list
let list = document.getElementById("shoppingList");
let newItem = document.createElement("li");
newItem.textContent = "Milk";
list.appendChild(newItem);


// Example 2: Create and add a button
let newButton = document.createElement("button");
newButton.textContent = "Click Me";
newButton.classList.add("btn");
newButton.onclick = function() {
    alert("Button clicked!");
};
document.body.appendChild(newButton);


// Example 3: Add new comment
function addComment(commentText) {
    let commentDiv = document.createElement("div");
    commentDiv.classList.add("comment");
    
    let author = document.createElement("strong");
    author.textContent = "User123";
    
    let text = document.createElement("p");
    text.textContent = commentText;
    
    commentDiv.appendChild(author);
    commentDiv.appendChild(text);
    
    let commentsSection = document.getElementById("comments");
    commentsSection.appendChild(commentDiv);
}

addComment("This is a great post!");


// Example 4: Create card element
function createCard(title, description) {
    let card = document.createElement("div");
    card.classList.add("card");
    
    let cardTitle = document.createElement("h3");
    cardTitle.textContent = title;
    
    let cardDesc = document.createElement("p");
    cardDesc.textContent = description;
    
    let cardBtn = document.createElement("button");
    cardBtn.textContent = "Learn More";
    
    card.appendChild(cardTitle);
    card.appendChild(cardDesc);
    card.appendChild(cardBtn);
    
    return card;
}

let myCard = createCard("JavaScript", "Learn JS easily");
document.body.appendChild(myCard);

7. REMOVING ELEMENTS
================================================================================

METHOD 1: remove()
------------------
- Removes element from DOM
- Modern and simple

HTML BEFORE:
<div id="myDiv">Remove me</div>

JAVASCRIPT:
let div = document.getElementById("myDiv");
div.remove();

HTML AFTER:
(element is gone)


METHOD 2: removeChild()
------------------------
- Parent removes a specific child
- Older method

HTML BEFORE:
<ul id="list">
  <li id="item1">Item 1</li>
  <li id="item2">Item 2</li>
</ul>

JAVASCRIPT:
let list = document.getElementById("list");
let item = document.getElementById("item1");
list.removeChild(item);

HTML AFTER:
<ul id="list">
  <li id="item2">Item 2</li>
</ul>


METHOD 3: Remove all children
------------------------------
// Method 1: Using innerHTML
let container = document.getElementById("container");
container.innerHTML = "";

// Method 2: Loop and remove
while(container.firstChild) {
    container.removeChild(container.firstChild);
}


PRACTICAL EXAMPLES:
-------------------

// Example 1: Remove button on click
let deleteBtn = document.getElementById("deleteBtn");
deleteBtn.addEventListener("click", function() {
    deleteBtn.remove();
});


// Example 2: Remove list item
let list = document.getElementById("taskList");
let lastItem = list.lastElementChild;
list.removeChild(lastItem);


// Example 3: Remove all items from list
let list = document.getElementById("myList");
list.innerHTML = "";


// Example 4: Remove on double click
let items = document.querySelectorAll(".item");
items.forEach(function(item) {
    item.addEventListener("dblclick", function() {
        item.remove();
    });
});

8. TRAVERSING THE DOM (Moving Between Elements)
================================================================================

Think of DOM as a family tree. Elements have parents, children, and siblings.

PARENT ELEMENTS:
----------------

parentElement - Gets parent element
------------------------------------
HTML:
<div id="parent">
  <p id="child">Child</p>
</div>

JAVASCRIPT:
let child = document.getElementById("child");
let parent = child.parentElement;
console.log(parent); // <div id="parent">


closest() - Find nearest ancestor matching selector
----------------------------------------------------
HTML:
<div class="container">
  <div class="inner">
    <button id="btn">Click</button>
  </div>
</div>

JAVASCRIPT:
let btn = document.getElementById("btn");
let container = btn.closest(".container");
console.log(container); // <div class="container">


CHILDREN ELEMENTS:
------------------

children - Get all child elements
----------------------------------
HTML:
<ul id="list">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

JAVASCRIPT:
let list = document.getElementById("list");
let items = list.children;
console.log(items.length); // 3
console.log(items[0]); // <li>Item 1</li>


firstElementChild - Get first child
------------------------------------
let list = document.getElementById("list");
let firstItem = list.firstElementChild;
console.log(firstItem); // <li>Item 1</li>


lastElementChild - Get last child
----------------------------------
let list = document.getElementById("list");
let lastItem = list.lastElementChild;
console.log(lastItem); // <li>Item 3</li>


SIBLING ELEMENTS:
-----------------

nextElementSibling - Get next sibling
--------------------------------------
HTML:
<div>
  <p id="first">First</p>
  <p id="second">Second</p>
  <p id="third">Third</p>
</div>

JAVASCRIPT:
let second = document.getElementById("second");
let next = second.nextElementSibling;
console.log(next); // <p id="third">Third</p>


previousElementSibling - Get previous sibling
----------------------------------------------
let second = document.getElementById("second");
let previous = second.previousElementSibling;
console.log(previous); // <p id="first">First</p>


PRACTICAL EXAMPLES:
-------------------

// Example 1: Highlight parent on child click
let button = document.getElementById("myBtn");
button.addEventListener("click", function() {
    let parent = button.parentElement;
    parent.style.backgroundColor = "yellow";
});


// Example 2: Remove all siblings
let element = document.getElementById("middle");
let parent = element.parentElement;
let siblings = parent.children;

for(let i = 0; i < siblings.length; i++) {
    if(siblings[i] !== element) {
        siblings[i].remove();
    }
}


// Example 3: Navigate list
let currentItem = document.getElementById("current");
let nextBtn = document.getElementById("nextBtn");
let prevBtn = document.getElementById("prevBtn");

nextBtn.addEventListener("click", function() {
    let next = currentItem.nextElementSibling;
    if(next) {
        currentItem.classList.remove("active");
        next.classList.add("active");
        currentItem = next;
    }
});

prevBtn.addEventListener("click", function() {
    let prev = currentItem.previousElementSibling;
    if(prev) {
        currentItem.classList.remove("active");
        prev.classList.add("active");
        currentItem = prev;
    }
});

9. EVENT HANDLING
================================================================================

Events = Things that happen in the browser
Examples: clicks, mouse movements, key presses, form submissions

SYNTAX:
-------
element.addEventListener(eventType, function);

eventType = Type of event (as a string)
function = Code to run when event happens


COMMON EVENT TYPES:
-------------------

MOUSE EVENTS:
- "click" - Element is clicked
- "dblclick" - Element is double-clicked
- "mousedown" - Mouse button is pressed down
- "mouseup" - Mouse button is released
- "mouseover" - Mouse enters element
- "mouseout" - Mouse leaves element
- "mouseenter" - Mouse enters element (doesn't bubble)
- "mouseleave" - Mouse leaves element (doesn't bubble)
- "mousemove" - Mouse moves over element

KEYBOARD EVENTS:
- "keydown" - Key is pressed down
- "keyup" - Key is released
- "keypress" - Key is pressed (deprecated)

FORM EVENTS:
- "submit" - Form is submitted
- "change" - Input value changes
- "input" - User types in input
- "focus" - Element gets focus
- "blur" - Element loses focus

DOCUMENT/WINDOW EVENTS:
- "DOMContentLoaded" - HTML is loaded and parsed
- "load" - Everything loaded (images, styles)
- "resize" - Window is resized
- "scroll" - User scrolls


BASIC EXAMPLES:
---------------

// Example 1: Click event
let button = document.getElementById("myBtn");
button.addEventListener("click", function() {
    alert("Button was clicked!");
});


// Example 2: Double click
let box = document.getElementById("box");
box.addEventListener("dblclick", function() {
    box.style.backgroundColor = "red";
});


// Example 3: Mouse over and out
let image = document.getElementById("myImg");

image.addEventListener("mouseover", function() {
    image.style.transform = "scale(1.2)";
});

image.addEventListener("mouseout", function() {
    image.style.transform = "scale(1)";
});


// Example 4: Keyboard events
let input = document.getElementById("myInput");

input.addEventListener("keydown", function(event) {
    console.log("Key pressed: " + event.key);
});

input.addEventListener("keyup", function() {
    console.log("You typed: " + input.value);
});


THE EVENT OBJECT:
-----------------
When event happens, JavaScript creates an EVENT OBJECT
This object contains information about the event

SYNTAX:
element.addEventListener("click", function(event) {
    // 'event' contains info about what happened
});

COMMON EVENT PROPERTIES:
- event.target - Element that triggered event
- event.type - Type of event ("click", "keydown")
- event.key - Which key was pressed (for keyboard events)
- event.clientX, event.clientY - Mouse position
- event.preventDefault() - Stop default behavior
- event.stopPropagation() - Stop event bubbling


EXAMPLE: Using Event Object
----------------------------
let button = document.getElementById("myBtn");

button.addEventListener("click", function(event) {
    console.log(event.target); // The button element
    console.log(event.type); // "click"
    console.log("Clicked at X: " + event.clientX + ", Y: " + event.clientY);
});


EXAMPLE: Keyboard Event
------------------------
document.addEventListener("keydown", function(event) {
    console.log("You pressed: " + event.key);
    
    if(event.key === "Enter") {
        console.log("Enter key was pressed!");
    }
    
    if(event.key === "Escape") {
        console.log("Escape key was pressed!");
    }
});


EXAMPLE: Prevent Default Behavior
----------------------------------
// Stop link from navigating
let link = document.getElementById("myLink");
link.addEventListener("click", function(event) {
    event.preventDefault();
    alert("Link click prevented!");
});

// Stop form from submitting (we'll handle it with JS)
let form = document.getElementById("myForm");
form.addEventListener("submit", function(event) {
    event.preventDefault();
    console.log("Form submission prevented");
    // Now we can handle form data with JavaScript
});


REMOVING EVENT LISTENERS:
--------------------------
Sometimes you need to remove an event listener

IMPORTANT: To remove, you need a NAMED function

// ❌ CAN'T REMOVE - Anonymous function
button.addEventListener("click", function() {
    alert("Hi");
});

// ✅ CAN REMOVE - Named function
function handleClick() {
    alert("Hi");
}
button.addEventListener("click", handleClick);
button.removeEventListener("click", handleClick);

10. EVENT DELEGATION
================================================================================

Problem: What if you have MANY elements that need same event listener?

BAD APPROACH: Add listener to each element
-------------------------------------------
let items = document.querySelectorAll(".item");
items.forEach(function(item) {
    item.addEventListener("click", function() {
        console.log("Clicked!");
    });
});
// Problem: Performance issues with many elements
// Problem: Doesn't work for dynamically added elements


GOOD APPROACH: Event Delegation
--------------------------------
Add ONE listener to parent, use event.target to identify child

HTML:
<ul id="list">
  <li class="item">Item 1</li>
  <li class="item">Item 2</li>
  <li class="item">Item 3</li>
</ul>

JAVASCRIPT:
let list = document.getElementById("list");

list.addEventListener("click", function(event) {
    // Check if clicked element is an item
    if(event.target.classList.contains("item")) {
        console.log("Clicked: " + event.target.textContent);
    }
});


WHY EVENT DELEGATION IS BETTER:
--------------------------------
✅ One listener instead of many (better performance)
✅ Works with dynamically added elements
✅ Less memory usage
✅ Easier to maintain


USING event.target.matches():
------------------------------
More flexible way to check if element matches selector

list.addEventListener("click", function(event) {
    if(event.target.matches(".item")) {
        console.log("Item clicked!");
    }
});

12. HTML COLLECTIONS VS NODELISTS
================================================================================

Both look like arrays but have differences!

HTML COLLECTION:
----------------
RETURNED BY:
- getElementsByClassName()
- getElementsByTagName()
- element.children

CHARACTERISTICS:
✅ Live - Updates automatically when DOM changes
✅ Has length property
✅ Can access by index: collection[0]
❌ No forEach method
❌ No array methods (map, filter, etc.)


NODELIST:
---------
RETURNED BY:
- querySelectorAll()
- childNodes

CHARACTERISTICS:
✅ Static (from querySelectorAll) - Doesn't update
✅ Has length property
✅ Has forEach method
✅ Can access by index: list[0]
❌ No map, filter, reduce methods (not a real array)


COMPARISON EXAMPLE:
-------------------

HTML:
<div id="container">
  <p class="text">Paragraph 1</p>
  <p class="text">Paragraph 2</p>
</div>

JAVASCRIPT:

// HTML Collection (Live)
let collection = document.getElementsByClassName("text");
console.log(collection.length); // 2

// Add new paragraph
let container = document.getElementById("container");
let newP = document.createElement("p");
newP.className = "text";
newP.textContent = "Paragraph 3";
container.appendChild(newP);

console.log(collection.length); // 3 (automatically updated!)


// NodeList (Static)
let nodeList = document.querySelectorAll(".text");
console.log(nodeList.length); // 2

// Add new paragraph (same as above)
container.appendChild(newP);

console.log(nodeList.length); // Still 2 (doesn't update!)


CONVERTING TO REAL ARRAY:
--------------------------
To use full array methods, convert to array:

METHOD 1: Array.from()
----------------------
let collection = document.getElementsByClassName("text");
let array = Array.from(collection);

// Now you can use array methods
array.forEach(function(element) {
    console.log(element.textContent);
});

array.map(function(element) {
    return element.textContent;
});


METHOD 2: Spread operator [...]
--------------------------------
let collection = document.getElementsByClassName("text");
let array = [...collection];

array.filter(function(element) {
    return element.textContent.includes("important");
});


METHOD 3: Array.prototype.slice.call()
---------------------------------------
let collection = document.getElementsByClassName("text");
let array = Array.prototype.slice.call(collection);


PRACTICAL EXAMPLES:
-------------------

// Example 1: Loop through HTML Collection
let items = document.getElementsByClassName("item");

// Traditional for loop
for(let i = 0; i < items.length; i++) {
    items[i].style.color = "blue";
}

// Convert to array and use forEach
Array.from(items).forEach(function(item) {
    item.style.color = "blue";
});


// Example 2: Filter NodeList
let paragraphs = document.querySelectorAll("p");

// Convert and filter
let longParagraphs = Array.from(paragraphs).filter(function(p) {
    return p.textContent.length > 100;
});

console.log("Long paragraphs: " + longParagraphs.length);


// Example 3: Map to get text content
let headings = document.querySelectorAll("h2");
let headingTexts = Array.from(headings).map(function(h) {
    return h.textContent;
});

console.log(headingTexts); // ["Heading 1", "Heading 2", ...]


WHICH ONE TO USE?
-----------------
✅ USE querySelectorAll:
   - More flexible (CSS selectors)
   - Has forEach built-in
   - Modern and recommended

⚠️ USE getElementsByClassName/TagName:
   - Need live collection
   - Slightly faster (but usually negligible)

14. BEST PRACTICES AND TIPS
================================================================================

1. USE MEANINGFUL VARIABLE NAMES
   ❌ let x = document.getElementById("btn");
   ✅ let submitButton = document.getElementById("submitBtn");


2. CACHE DOM SELECTIONS
   If you use an element multiple times, select it once
   
   ❌ BAD:
   document.getElementById("btn").textContent = "Click";
   document.getElementById("btn").style.color = "red";
   document.getElementById("btn").classList.add("active");
   
   ✅ GOOD:
   let button = document.getElementById("btn");
   button.textContent = "Click";
   button.style.color = "red";
   button.classList.add("active");


3. USE addEventListener, NOT INLINE HANDLERS
   ❌ <button onclick="doSomething()">Click</button>
   ✅ button.addEventListener("click", doSomething);


4. ALWAYS preventDefault FOR FORMS
   ✅ Always prevent default form submission
   
   form.addEventListener("submit", function(event) {
       event.preventDefault();
       // Your code here
   });


5. USE EVENT DELEGATION FOR LISTS
   ✅ One listener on parent, not many on children
   
   parent.addEventListener("click", function(event) {
       if(event.target.matches(".item")) {
           // Handle click
       }
   });


6. USE classList, NOT className
   ❌ element.className = "class1 class2";
   ✅ element.classList.add("class1", "class2");


7. VALIDATE USER INPUT
   ✅ Always check and validate form data
   
   if(input.value.trim() === "") {
       alert("Field cannot be empty");
       return;
   }


8. USE TEMPLATE LITERALS FOR DYNAMIC CONTENT
   ❌ element.textContent = "Hello " + name + "!";
   ✅ element.textContent = `Hello ${name}!`;


9. CHECK IF ELEMENT EXISTS BEFORE USING
   ✅ Prevent errors if element not found
   
   let element = document.getElementById("myId");
   if(element) {
       element.textContent = "Found!";
   } else {
       console.log("Element not found");
   }


10. USE DESCRIPTIVE FUNCTION NAMES
    ❌ function x() { }
    ✅ function handleFormSubmit() { }
    ✅ function validateEmail() { }


11. BREAK DOWN COMPLEX PROBLEMS
    Don't try to solve everything at once
    - Step 1: Select element
    - Step 2: Add event listener
    - Step 3: Get values
    - Step 4: Validate
    - Step 5: Display result


12. CONSOLE.LOG FOR DEBUGGING
    ✅ Use console.log to check:
    - Is element selected? console.log(element)
    - What's the value? console.log(value)
    - What's in event object? console.log(event)


13. COMMENT YOUR CODE
    ✅ Add comments to explain complex logic
    
    // Validate email format
    if(!email.includes("@")) {
        showError("Invalid email");
    }


14. LEARN BY DOING
    ✅ Practice on real websites (browser console)
    ✅ Build small projects
    ✅ Experiment and break things
    ✅ Read MDN documentation


15. MODERN vs OLD METHODS
    ✅ MODERN (Use these):
    - querySelector/querySelectorAll
    - addEventListener
    - classList
    - element.remove()
    
    ⚠️ OLD (Still works but outdated):
    - document.write()
    - element.onclick = function
    - className manipulation
